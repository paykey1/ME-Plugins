## Distribution

This repository hosts reviewed plugin ZIP packages, a signed catalog, and the trusted validation and packaging workflow. Full source submissions and review documents remain in private storage. Installed JavaScript code is visible to users. Review does not guarantee safety.

Submit from the Plugin Center in the ME desktop application after signing in. The workflow validates and packages approved files without running submitted scripts.
